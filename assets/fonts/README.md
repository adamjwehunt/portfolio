# Fonts

Self-hosted Latin subsets of [Roboto](https://fonts.google.com/specimen/Roboto) and
[Share Tech Mono](https://fonts.google.com/specimen/Share+Tech+Mono), downloaded from
Google Fonts and loaded with `next/font/local` in `constants/fonts.ts`.

Both fonts are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org).

They are self-hosted so builds don't depend on fetching from Google Fonts.
